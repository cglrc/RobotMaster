# 串口协议 2026.3.11
## 第一部分 上位机发送

### 发送数据格式
- #### （一）多个飞镖的参数
	- ##### 1、发送类型（有效值1~4，单个飞镖的值设为Single）

```cpp
enum VisionMode
{
	Single = 0,
	First = 1,
	Second = 2,
	Third = 3,
	Fourth = 4,
};
```

- #### （二）单个飞镖的参数
	- ##### 2、转速/拉簧长度（例如 4500 rad/m 或 17.13mm）* 100
	- ##### 3、偏航（Yaw）角度当前值（例如3.56 * 100 °）

```cpp
int16_t send_yaw_data;
int16_t send_yaw_add_data;
int16_t send_motor_value_data;
uint8_t send_type_data;
uint8_t send_flag_data;
uint8_t save_level;

VisionData[2] = send_yaw_data >> 8 * 0; // yaw视觉角
VisionData[3] = send_yaw_data >> 8 * 1; 
VisionData[4] = send_yaw_add_data >> 8 * 0; // yaw补偿值
VisionData[5] = send_yaw_add_data >> 8 * 1; 
VisionData[6] = send_motor_value_data >> 8 * 0; // 电机值
VisionData[7] = send_motor_value_data >> 8 * 1;
VisionData[8] = send_type_data; // 镖体序号（0表示自由测试模式，1、2、3、4表示修改制定镖体参数）
VisionData[9] = send_flag_data; // 检测标志（0表示待识别状态，1表示识别中和计算视觉角，2表示结束识别，3表示锁定状态）
VisionData[10] = save_level; // 保留位
```

## 第二部分 下位机发送
```cpp
int16_t Yaw_angle; // 镖架当前yaw角度
int16_t pulling_force; // 拉簧拉力
uint8_t aim_finish_flag; // 瞄准完成标志位
uint8_t save_level; // 保留位

VisionData[2] = Yaw_angle >> 8 * 0; // 镖架当前yaw角度
VisionData[3] = Yaw_angle >> 8 * 1;
VisionData[4] = pulling_force >> 8 * 0; // 拉簧拉力
VisionData[5] = pulling_force >> 8 * 1;
VisionData[6] = aim_finish_flag; // 瞄准完成标志位（默认为0.每次镖架运动结束时+1，比赛结束、比赛准备开始时或发射次数用完时重置为0。视觉方每次收到值自增1时重置检测状态，收到值归0时解除锁定状态，回到待命状态）
VisionData[7] = DartIndex; // 镖号索引
VisionData[8] = save_level; // 保留位
```

## 第三部分 通讯流程

> ⚠️ **读前须知**：每次电机到达位置时，瞄准完成标志 `aim_finish_flag` 均会 +1；比赛结束、比赛准备开始时或发射次数用完时重置为0。

| 阶段 | 状态描述 | 视觉检测标志send_flag_data | 电控瞄准完成标志aim_finish_flag | 说明 |
|------|--------|-----------------|-----------------|------|
| 1 | 待命状态 | 0（未识别） | 0 | 飞镖系统待命阶段 |
| 2 | 识别状态 | 1（识别中） | 0 | 舱门开启后，上位机视觉识别引导灯的阶段 |
| 3 | 识别完成 | 2（结束识别） | 0 | 计算精准yaw并发送数据给下位机的阶段 |
| 4 | 运动状态 | 2（结束识别） | 0 | 下位机接收yaw后，电机开始运动的阶段 |
| 5 | **运动完成** | 2（结束识别） | **1** | 电机到达目标位置，标志位更新 |
| 6 | 识别校正 | 1（识别中） | 1 | 上位机重启识别功能，校正镖架位置的阶段 |
| 7 | 识别完成 | 2（结束识别） | 1 | 计算精准yaw并发送数据给下位机的阶段 |
| 8 | 运动状态 | 2（结束识别） | 1 | 下位机接收yaw后，电机开始运动的阶段 |
| 9 | **运动完成** | 2（结束识别） | **2** | 电机到达目标位置，标志位更新 |
| 10 | …… | …… | ……| …… |
| 11 | 锁定状态 | 3（锁定状态） | **n** | 锁定状态，表示上位机完成任务 |

**流程说明：**

- **阶段 1-4**：初始识别和运动流程
- **阶段 5**：关键转折点 🔄
  - 电控瞄准完成标志位 `aim_finish_flag` **+ 1**
  - 由于下位机更新瞄准完成标志位，上位机重启识别功能
  - 视觉重置检测标志 `send_flag_data` 为 0（未识别状态）
- **阶段 6-9**：校正循环
  - 重复阶段 2-4 的识别、计算和运动过程
  - 循环上述步骤，直至视觉 yaw 角度 **< 0.23°（电机运动最小值）**

- **阶段11**：锁定状态：锁定状态，表示上位机完成任务。瞄准完成标志位归0时退出锁定状态，回到待命状态
